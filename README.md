# Minigame 1
## Devlog
I think a good metaphor that can be used to describe the relationship between GameObjects, their components, and the scene they're in would be
saying they're like making a dish in the kitchen. The GameObjects are the ingredients--molded by techniques and resources into a complete element that is in the dish.
The components are represented by the knives and other tools you'd use to change the GameObjects, altering their properties and making them behave differently.
The scene could either be the plate or bowl that contains everything you've made, or you could also see the bowl as a parent object to all the child GameObjects,
and the kitchen would be the Scene instead. In any case, either of these two things could be the scene because they enable the creation and collection of these objects.
